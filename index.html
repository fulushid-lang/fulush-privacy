Kebijakan Privasi Fulush / Privacy Policy

Berlaku efektif / Effective date: 16 November 2026

Bahasa Indonesia

1. Prinsip Utama (Lokal-Utama)

Fulush dirancang agar seluruh catatan keuangan Anda tetap berada di perangkat Anda sendiri secara bawaan. Fulush tidak menampilkan iklan, tidak memakai SDK pelacakan/analitik pihak ketiga, dan tidak menjual data pengguna.

2. Data yang Diproses & Tujuannya

  • Catatan Keuangan Lokal: Transaksi, draf, anggaran, saldo dompet, aturan rutin, target tabungan, kategori kustom, dan preferensi disimpan secara lokal di database SQLite perangkat.
  • Akses Notifikasi (Opsional): Jika diaktifkan, Fulush hanya membaca notifikasi dari aplikasi dompet digital/bank yang Anda pilih di Aplikasi dipantau untuk mendeteksi nominal, toko/penerima, dan jenis transaksi. Teks asli notifikasi dan log notifikasi hanya disimpan di perangkat dan tidak pernah diunggah.
  • Pindai Struk / OCR (Opsional): Foto dari kamera, galeri, atau menu Bagikan diproses di perangkat melalui Google Play Services ML Kit Text Recognition. File sementara dihapus segera setelah dipindai.
  • Bantuan Gemini (Opsional, mati bawaan): Jika dinyalakan, hanya kalimat yang Anda ketik di Catat dari kalimat, daftar nama kategori, dan tanggal hari ini yang dikirim ke API Google Gemini (lewat proxy fulush-gemini.fulush-app.workers.dev atau kunci API Anda sendiri). Proxy tidak menyimpan isi kalimat Anda.
  • Sinkronisasi Online (Opsional, Login Google): Jika masuk dengan Google, transaksi terkonfirmasi, penanda hapus, anggaran, saldo acuan, transaksi rutin, target tabungan, mata uang tampilan, serta ikon aplikasi dompet terpasang disinkronkan ke Firebase Firestore di bawah jalur akun Anda (users/{uid}/...).
  • Kurs Mata Uang: Mengambil kurs publik dari open.er-api.com tanpa mengirim identitas atau data keuangan Anda.

3. Penghapusan Akun & Data Pengguna

Anda dapat mengekspor cadangan (JSON/CSV) maupun menghapus seluruh data Anda kapan saja langsung di dalam aplikasi Fulush:

  • Hapus akun & data cloud: Buka Pengaturan → Sinkron online → Hapus akun & data cloud untuk menghapus permanen seluruh data Firestore (termasuk wallet_icons) dan akun Firebase Auth Anda.
  • Hapus data perangkat: Buka Pengaturan → Cadangan → Hapus semua data di perangkat untuk menghapus seluruh data lokal SQLite, log notifikasi, preferensi, dan kunci Gemini tersimpan.

English

1. Core Principle (Local-First)

Fulush stores your financial records locally on your device by default. Fulush has no ads, no third-party analytics or crash-reporting SDKs, and never sells user data.

2. Data Processed & Purpose

  • Local Financial Data: Transactions, drafts, budgets, wallet balances, recurring rules, savings goals, custom categories, and app preferences stay in local SQLite storage.
  • Notification Access (Optional): When enabled, Fulush reads notifications solely from wallet/bank apps you select under Watched apps to detect amounts, merchants, and transaction types. Raw notification texts and logs remain strictly on-device and are never uploaded.
  • Receipt Scanning / OCR (Optional): Images from camera, gallery, or Share are processed on-device via Google Play Services ML Kit Text Recognition. Temporary files are deleted right after scanning.
  • Gemini Assist (Optional, off by default): Only the sentence you type in Add from a sentence, category names, and today's date are sent to Google Gemini (via fulush-gemini.fulush-app.workers.dev or your own API key). The proxy server does not log sentence contents.
  • Online Sync (Optional, Google Sign-In): Confirmed transactions, tombstones, budgets, balance anchors, recurring rules, savings goals, display currency, and installed wallet icons sync strictly under your own Firebase path (users/{uid}/...).
  • Exchange Rates: Fetches public conversion rates from open.er-api.com without sending personal identifiers or financial data.

3. Account & Data Deletion

You can export JSON backups or CSV anytime, permanently erase all Firestore cloud copies and delete your Firebase Auth account via Settings → Online sync → Delete account & cloud data, or wipe all local device storage via Settings → Backup → Erase all device data.
